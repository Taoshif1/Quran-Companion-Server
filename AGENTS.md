# Persistent project instructions

1. Quran content may never be generated, rewritten, transliterated, corrected, or otherwise modified.
2. Quran Foundation / Quran.com is the authoritative application content source.
3. Never expose server credentials or place them in client-side environment variables.
4. Keep source files readable, normally formatted, and maintainable.
5. Preserve mobile-first responsive behavior across changes.
6. Maintain the offline-first reader behavior and source integrity.
7. Do not add major features outside the active phase.
8. Run lint, build, and relevant tests before commits.
9. Never commit `.env`.
10. Ask before any destructive Git operation.
