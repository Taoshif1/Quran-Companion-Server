# Quran Companion Server

The Express proxy for Quran Foundation Content APIs. It keeps confidential credentials server-side and returns normalized data to the client.

Built by **Gazi Taoshif** as the backend for Quran Companion. For commercial web and product work, visit **[Taoshiflex Studio](https://taoshiflexstudio.me)**.

Copy `.env.example` to `.env`, add your Quran Foundation application credentials, and run `npm run dev`.
