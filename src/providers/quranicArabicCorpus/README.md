# Quranic Arabic Corpus provider (pending official source)

The word-study provider is intentionally disabled. Quranic Arabic Corpus 0.4 requires an email address and explicit GNU GPL acceptance on its official download page: https://corpus.quran.com/download/.

No mirror or scraped copy is accepted. When the official files are supplied, the importer will keep the source untouched, record its checksum and license, and map corpus locations to canonical Tanzil verse keys without changing either source.
