# Third-Party Notices

## Tanzil Project Quran Text

Quran Companion includes the Tanzil Project Uthmani Quran Text, version 1.1, obtained from [Tanzil Project](https://tanzil.net/download/).

Permission is granted by Tanzil to copy and distribute verbatim copies of its Quran text. Changing the text is not allowed. Applications using the text must clearly indicate Tanzil Project as the source and link to [https://tanzil.net/](https://tanzil.net/) so users and developers can track source changes.

The canonical downloaded XML is retained unchanged under `data/source/tanzil/`. Its source manifest records its filename, release, official URL, download date, and project-local SHA-256 integrity checksum. That checksum detects modification of this project copy; it is not an independent religious-authenticity proof.

Tanzil describes its Uthmani text as representing the Medina Mushaf. Quran Companion is not endorsed by the King Fahd Complex.

## QuranEnc translations of meaning

Bengali translations of meaning, when available, are retrieved from [QuranEnc.com](https://quranenc.com/). QuranEnc requires republished translation content to remain unmodified, identify QuranEnc as publisher/source, retain version information, and be kept current with source releases.

Quran Companion keeps translation text and footnotes separate, preserves the selected resource key and version, and never silently substitutes another resource or version.
